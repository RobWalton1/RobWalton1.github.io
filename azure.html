Azure Infrastructure Lab

A hands-on project for developing cloud infrastructure, identity and security skills through a documented Azure environment.

Project focus

This project is a place to apply Azure concepts in a deliberate, practical way: designing an environment, configuring it thoughtfully and recording the reasoning behind each decision. The emphasis is on secure foundations and repeatable operations—not simply provisioning services.

What I’m working on

  • Resource organisation
  • Identity and access
  • Network security
  • Monitoring and logging
  • Cost awareness
  • Infrastructure documentation

Approach

Each part of the lab is treated as a small, explainable implementation: define the requirement, choose an Azure service, apply least-privilege and sensible defaults, then validate and document the outcome. This keeps the work useful as both a learning record and a foundation for future cloud projects.

Status: In development. This page will grow with architecture notes, implementation evidence and lessons learned as the lab evolves.
