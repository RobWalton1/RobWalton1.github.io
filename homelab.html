HOMELAB

Network Security Lab & Penetration Testing Environment

Project Overview

A fully virtualized cybersecurity testing environment demonstrating network segmentation, intrusion detection, vulnerability assessment, and penetration testing methodologies.

Infrastructure Components (In Development)

  • Hypervisor setup (Hyper-V / VMware)
  • Network segmentation with VLANs
  • Firewall configuration & rules
  • Intrusion Detection System (Suricata/Snort)
  • Log aggregation & SIEM
  • Honeypot deployment
  • Vulnerability scanning environment
  • Penetration testing lab

Tools & Technologies

Virtualization: Hyper-V, VirtualBox
Networking: pfSense, OpenWrt
Security Tools: Metasploit, Burp Suite, Wireshark
Monitoring: Grafana, Prometheus, ELK Stack
OS Testing: Windows Server, Linux, Kali Linux

Learning Objectives

  • Network architecture & design
  • Vulnerability identification & remediation
  • Incident response procedures
  • Malware analysis techniques
  • Security hardening practices
  • Compliance & security standards
