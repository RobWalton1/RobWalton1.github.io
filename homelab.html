Self-hosted infrastructure

Home Lab

A self-hosted environment for storage, media and containerised development workloads.

Project focus

The home lab is a practical, self-hosted platform used as a personal file system, a media server and a place to run my own code. It combines dependable day-to-day services with an environment for learning systems administration and infrastructure practices.

How it is used

  • File storage
  • Jellyfin media playback
  • Containerised applications
  • Personal code workloads
  • Service monitoring
  • Backups

Infrastructure approach

Services are isolated in containers where appropriate, making them easier to deploy, update and maintain. The setup provides a controlled place to run and test personal projects while keeping file storage and multimedia playback available as useful, everyday services.
